# Cross stitch: to-do and ideas

Ideas for the cross-stitch pattern maker, roughly in the order they came up. Nothing here is decided; move things up, down, or out as the tool takes shape.

## In progress

- **Text.** Type words, choose a font, and set the size and layout, for a little "Home sweet home" piece. Choosing the font matters most. The text floats over the chart until it's placed, so it can be dragged into position first. A first version works: three stitch alphabets (crisp at any size) and seven smooth fonts, with letter height, alignment, and spacing between lines and letters. Still to try: more fonts, text on a curve (for a round hoop), and choosing the text color separately from the palette.

## To do

- **Real thread colors.** Match each color to a real thread, such as a DMC floss number, so the legend becomes a shopping list. This matters most for actually stitching a pattern.
- **Clean up single stitches.** Stray one-off stitches of a color ("confetti") are tedious to sew. An option could merge them into their neighbors.
- **Save in the browser.** Keep the work in progress between visits, so closing the tab doesn't lose it. Today nothing is kept unless a pattern file is saved.
- **More from the PDF.** A choice of A4 paper (it's US Letter for now), and thread numbers in the color key once real thread colors land.
- **Bug: a fully transparent photo crashes the tool.** It makes a pattern with no colors, and drawing the color picker fails on the empty palette.
- **Selection: move, copy, and paste.** Select part of the pattern (a drawing, part of a photo, or text) and drag it somewhere else on the grid to arrange the layout. Copy and paste, so one small butterfly or flower can be placed several times. Text already floats before it's placed, so this can reuse that.
- **Printing without color ink.** A grayscale mode, and a symbols-only mode that drops the colors and leaves just the symbols on white. Show symbols can already be turned on and off.
- **Round charts for a hoop.** Show the chart as a circle, so a pattern can fill a round embroidery hoop without working out how it fits in a square. First find out how stitchers usually handle this.
- **A "How it works" page.** How a photo becomes stitches and how colors are reduced. The design system asked for one for every experiment; as its own app it's optional. Write it once the design settles.

## Already there

- **Saving.** Three kinds of file: a PDF to print and stitch from (cover, color key, and a chart across pages), a PNG image of the chart to share, and a pattern file to open again and keep editing.
- **Free drawing.** Pick a color and click or drag on the chart to stitch; the eraser takes stitches out. Drawing tools could come later: straight lines, rectangles, and a fill bucket.
